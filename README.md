# 命盘

一个八字命盘工具：输入生辰，输出四柱、五行能量、喜用与调理、命格、十神、神煞、大运流年，以及一段人生课题的收束。

**所有计算在浏览器本机完成，出生信息不上传，没有后端，不联网也能用。**

## 使用

打开 `index.html` 即可。整个工具是单个 HTML 文件，包含排盘引擎，可以直接下载、离线打开、通过聊天软件发送。

## 功能

- **公历／农历输入**，含闰月，滚轮选择
- **真太阳时校正**：按出生地经度 + 均时差换算，过程完整显示，可复核
- **省市二级联动**：34 个省级行政区、341 个城市的真实经度，不用省会一刀切
- **夏令时提醒**：1986–1991 年中国夏令时，以及海外地区的夏令时提示
- **时辰边界告警**：真太阳时距离时辰交界十分钟内会提示时柱可能落错
- 四柱、藏干、主星副星、星运、自坐、空亡、纳音、神煞
- 五行能量（传统扶抑法）、命格（月令取格）、喜用与调理
- 十神虚实判定与十神组合（官印相生、财官双美等）
- 特殊格局检测：三合局、三会方、三奇贵人、天干一气、从格与专旺候选
- 大运流年：十神主题、喜忌判定、与原局的冲合、与原局主力的组合

## 方法与边界

- 旺衰、取格、喜用采用**传统扶抑法**，是目前最通行的一套。盲派、格局派判法不同，结论可能有出入。
- 神煞中桃花、驿马、华盖、将星、劫煞以**日支**起；红鸾、天喜、孤辰、寡宿只有年支起法。
- 冲合只做**天干五合、地支六冲、地支六合**。三合与各类刑没有纳入，因为各家判法出入较大。
- 从格与专旺采用**结构判定**（无本气根且天干无帮扶），不用分数阈值，并且只提示候选，不下结论。
- 本工具不对疾病、寿命和具体灾祸作任何判断。

命盘描述的是配置和倾向，不是结局。
